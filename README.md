# Bootcamp-multi-platform-dashboard
☕ **Coffee Shop Analytics – Multi Platform Dashboard Project**

**📌 Overview**

This project demonstrates how the same coffee shop sales dataset can be transformed into business insights across multiple analytics platforms:
- Google Looker Studio
- Microsoft Excel
- Databricks SQL

  The objective was to compare dashboard design, usability, and reporting capabilities across tools.

  📊 **Platforms Used:**
  
  1.Google Looker Studio
  
  2. Databricks
     
  3. PowerBI

**Dataset**

Coffee shop transactional sales data including:

- Revenue
- Product Category
- Store Location
- Date
- Daily Sales

**Key Insights**

- Revenue split evenly across 3 stores
- Highest sales occurred on weekends
- Morning hours generated peak transactions
- Coffee products drove most revenue
